# Laudo de qualidade

O laudo oficial é gerado pelo próprio sistema em **Avaliar → Laudo de qualidade** (`/feedback/laudo`, só para o administrador). Lá ficam todas as avaliações com os prints anexados, a situação de cada problema e a correção feita. O botão **Imprimir / salvar PDF** gera o arquivo para a entrega.

## Como preencher

1. Envie o [roteiro](02-roteiro-para-testadores.md) aos 5 testadores.
2. Acompanhe as avaliações no laudo. Para cada problema relatado:
   - corrija no código, com um commit cujo título descreva a correção;
   - no laudo, marque **Corrigido** e descreva o que foi feito, citando o commit;
   - se o problema não proceder (por exemplo, um comportamento esperado), marque **Não procede** e explique o motivo.
3. Gere o PDF e copie o resumo abaixo para a atividade de entrega.
